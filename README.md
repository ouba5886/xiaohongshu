# 小鸡发财去水印批量下载助手v1.0.2 (Chrome 扩展程序)

专为小红书网页端（xiaohongshu.com）打造的高清无水印批量下载工具。

## ✨ 核心特性（完美契合 3 项刚性要求）

1. **100% 官方无水印原图与高清视频**：
   - 图片通过底层 `traceId` 直连小红书官方原图 CDN 通道，彻底剥离平台水印 Logo 及裁剪参数。
   - 视频智能提取最高码率源视频流（H.264/H.265 MP4），无任何平台贴片水印。
   - 支持实况照片（Live Photo）的无水印照片与短视频合并归档。
2. **一个博主一个文件夹，井然有序**：
   - 自动识别当前博主昵称与 ID。
   - 文件自动归档至：`系统下载目录/小红书下载/{博主昵称}/{笔记标题}_{序号}.jpg`，多博主互不干扰。
   - 自动清洗 Windows/Mac 非法文件名特殊字符，防止下载报错。
3. **严格保证照片格式为标准 JPG**：
   - 内置前端 Canvas / ImageDecoder 转码引擎。
   - 即便小红书 CDN 下发的是 WebP 或 AVIF 格式，插件也会统一重构为标准 JPEG 二进制数据，确保保存的文件 100% 为标准 JPG，在任何第三方看图软件和移动设备上都能直接查看。

## 🚀 安装步骤（1 分钟搞定）

1. 打开 Chrome 浏览器，在地址栏输入并回车访问：
   ```text
   chrome://extensions/
   ```
2. 在扩展程序页面**右上角**，打开 **「开发者模式」**（Developer Mode）开关。
3. 点击左上角的 **「加载已解压的扩展程序」**（Load unpacked）按钮。
4. 在弹出的文件选择窗口中，选中本项目所在的文件夹：
   ```text
   /Users/ouba/Desktop/456
   ```
5. 安装完成！在 Chrome 工具栏即可看到「小鸡快发财」的小鸡图标。

## 📖 使用教程

### 场景一：批量下载博主全部照片和视频
1. 打开 Chrome 浏览器，访问任意小红书博主的个人主页（如 `https://www.xiaohongshu.com/user/profile/...`）。
2. 页面右下角会自动出现可爱的 **「🐥 小鸡快发财」** 悬浮胶囊按钮，并展示已扫描到的笔记数。
3. 点击展开控制面板：
   - 点击 **「🚀 自动扫描当前博主」**：页面会自动平滑向下滚动，自动捕获博主发布的所有历史笔记；
   - 点击 **「全选 / 仅选图文 / 仅选视频」** 自由筛选内容；
   - 点击 **「⬇️ 批量下载选中项 (JPG无水印)」** 开始下载。
4. 插件将实时展示下载与转码进度条，所有文件将自动按博主归类保存在您的电脑「下载」目录中的 `小红书下载/{博主名称}/` 文件夹下。

### 场景二：浏览时单篇笔记即时下载
1. 在小红书点击打开任意一篇笔记弹窗。
2. 笔记右上角会自动出现 **「📥 下载本篇无水印原图(JPG)」** 快捷按钮。
3. 点击即可立即一键无水印下载本篇全部照片（转为 JPG）或高清视频。

## ⚙️ 快捷配置说明（控制面板内可随时切换）

- **照片强制转为 JPG**：默认开启。保证文件格式纯正，所有系统均可打开。
- **按博主保存为独立文件夹**：默认开启。一个博主建立一个文件夹。
- **包含 LivePhoto 实况短视频**：默认开启。检测到实况照片时，同步下载其对应的 MP4 短视频。
